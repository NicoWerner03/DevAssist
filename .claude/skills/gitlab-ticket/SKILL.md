# GitLab Ticket Fetching Skill for Claude Code

This skill allows Claude Code to fetch the complete context of a specific GitLab ticket or issue using the `glab` CLI.

## Instructions

When the user asks to "get ticket X", "show issue Y", "view gitlab issue Z", or similar, run the following command to retrieve the ticket description and discussion comments:

```bash
glab issue view <ticket-id-or-number> --comments
```

### Specifying a Repository

If Claude is not running in the target project's local git folder, or if you need to fetch from a different repo, resolve the repository namespace and use the `-R` flag:

```bash
glab issue view <ticket-id-or-number> -R <group/subgroup/project> --comments
```

### Safety and Context Verification
- Always execute `glab auth status` first if you suspect you are not authenticated.
- Read both the issue description and the comments to understand the requirements.
- Use the structured proposal generated by dev-assist (marked with `## Dev-Assist: Structured Proposal`) as the source of truth for the task implementation.
